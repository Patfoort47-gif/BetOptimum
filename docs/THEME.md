# BET-190 · Thème système et préférence

`theme-bootstrap.js` est un script synchrone dans le head avant les styles : il valide light/dark et applique le choix avant le rendu. Sans préférence valide, il suit prefers-color-scheme et ses changements. Un choix manuel prime sur le système ; en cas de stockage bloqué, il reste actif pour la session. Les événements storage synchronisent les onglets, y compris la suppression de préférence. Le bouton est un switch « Thème sombre », avec aria-checked et activation clavier native. La couleur du navigateur est synchronisée.

Recette : `NODE_PATH=/tmp/bet-ui-tools/node_modules node scripts/check-theme.cjs`, serveur 4173. Huit combinaisons système/préférence (absente, invalide, clair, sombre), rechargement, clavier, onglets et stockage refusé. Huit largeurs 375 à 1440 px en clair et sombre : pas de débordement, audit axe color-contrast sur cartes et filtres, aide ouverte et fenêtre d’aide. Aucun échec détecté sur ces contrôles automatisés ; les graphismes sportifs décoratifs ne constituent pas du texte à lire. Les tokens sémantiques et focus existants sont conservés. 385 tests Node réussis, préparation Pages avec le bootstrap incluse.

BET-229 : le comportement demandé est déjà livré par BET-190. Les tests `tests/theme-system.test.js` vérifient désormais l’application synchrone avant rendu, le suivi des changements système, la priorité du choix manuel, le stockage bloqué et la suppression inter-onglets. Aucun second mécanisme de thème n’est ajouté.
