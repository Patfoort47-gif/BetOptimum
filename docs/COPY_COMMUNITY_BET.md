# BET-203

Depuis les paris publics d’un profil, Copier le pari préremplit le ticket avec les cotes actuelles et le pseudo d’origine. Une sélection fermée ou indisponible refuse toute la copie. Le joueur ajuste sa mise et confirme lui-même le pari. Les mises et bankrolls du joueur d’origine restent privées. Les systèmes ne sont pas copiés. Appliquer V51 avant publication : la provenance est vérifiée côté serveur depuis public_bets puis conservée dans l’historique.

Validation : suite Node complète et recette navigateur locale avec données fictives ; aucun envoi réel ni modification des paris de production.
