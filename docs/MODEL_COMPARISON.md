# Toi contre le modèle (BET-319)

Le profil personnel affiche le ROI normalisé du joueur et celui du modèle sur les **mêmes matchs**, dans les paris certifiés chargés de la semaine en cours. Une unité constante par match de chaque côté évite qu'une mise élevée domine le comparatif ; ce n'est donc pas le ROI pondéré réel du compte. Pour plusieurs simples sur un match, le dernier pari réglé est retenu. Combinés, systèmes, anciens paris locaux, remboursés, paires manquantes et cotes modèle/inconnues sont exclus des deux côtés.

La comparaison utilise le statut et la cote certifiés du joueur ainsi que le pronostic réel déjà archivé du modèle. Les marchés peuvent différer : c'est une comparaison des choix sur un même match. Le manque de paires est affiché explicitement. Les autres profils ne voient ni cette rubrique ni ses données ; aucun nouvel accès public/RPC n'est ajouté.

Le partage volontaire génère localement un PNG avec les deux pourcentages, l'effectif, la période et la méthode. Aucune identité, mise, bankroll, liste de paris ou identifiant de match n'y figure. Partage natif ou téléchargement de secours, sans téléversement. Les résultats passés n'offrent aucune garantie. Tests purs : appariement, déduplication, normalisation, exclusions symétriques et confidentialité du contenu.
