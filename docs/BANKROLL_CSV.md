# BET-204

L’export CSV utilise export_my_data afin d’inclure tout l’historique certifié. Il propose période libre, année et mois en cours. UTF-8 avec BOM et séparateur point-virgule ; les champs sont échappés, y compris les cellules pouvant devenir des formules. Le capital après règlement est reconstruit à partir de tous les mouvements, même si la sélection de dates est partielle. Les paris en attente n’affichent aucun gain acquis.

Validation : suite Node complète et recette navigateur locale avec données fictives ; aucun envoi réel ni modification des paris de production.
